# CAD Design

This folder contains the mechanical design and CAD development of the warehouse AMR.

The current design includes the chassis, Mecanum wheel arrangement,
structural supports, electronics mounting and forklift mechanism.

The CAD model is still under development and will be optimized
for conversion into a ROS 2 robot description.
