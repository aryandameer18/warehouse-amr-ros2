# Warehouse AMR — ROS 2 & Gazebo

 **Work in Progress**

A warehouse Autonomous Mobile Robot (AMR) project focused on CAD design, robot modeling, ROS 2, and Gazebo simulation.

##  Project Overview

The goal of this project is to design and simulate a warehouse mobile robot capable of transporting and handling loads.

The project is being developed step-by-step, starting from the mechanical design and eventually moving toward ROS 2 and Gazebo simulation.

##  Technologies

* CAD / 3D Modeling
* ROS 2
* Gazebo
* URDF / Xacro
* Python
* Linux
